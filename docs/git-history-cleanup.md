# History note

This repository was created from a private predecessor (`restaurant-agent`) by rewriting its Git history before the code was published for review.

## Why

Early development recorded real Google Places responses (place ids, names, addresses, coordinates, ratings and review counts, opening hours, Maps links) and used them in test fixtures, demo data and UI screenshots. Google's terms restrict storing Places content, so none of it is kept here.

## What was done

- The recorded fixtures and the screenshots rendered from them were removed from every commit; the current fixtures and screenshots are **synthetic** (fictional restaurants, invented ratings, `.example` addresses), generated by `scripts/synthesize-fixture.mjs`.
- Real restaurant names and review counts that appeared in demo data and test expectations were replaced by the same fictional values used in the current tree.
- Commit hashes mentioned in older documents under `docs/` refer to the predecessor repository and no longer exist; the commit messages and order are unchanged.
- No credentials were ever present in the history (checked), so no keys needed rotating.

## Verification performed on this history

Across every revision: no Google place ids, none of the original restaurant names, none of the original review counts, no `.env` files (other than `.env.example`), no raw recordings, and no key-shaped strings.

## Keeping it clean

Raw provider recordings belong in `fixtures/raw/` (git-ignored). Convert them to synthetic fixtures with `node scripts/synthesize-fixture.mjs <raw.json> <out.json>` before committing anything.
